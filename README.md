# CSN Project 2026

This repository contains the documentation, simulation files, and configurations for the **Connecting and Securing Networks** course project. The primary goal is the design and implementation of a redundant, self-healing enterprise network.

---

## 📄 Project Overview
The objective of this project is to integrate advanced networking techniques into a cohesive infrastructure. We focus on building a resilient network capable of automatic recovery from link or device failures.

The project follows a structured four-phase methodology:
1. **Preparation:** Research and theoretical design.
2. **Simulation:** Scenario testing using Cisco Packet Tracer.
3. **Implementation:** Deployment on physical hardware in a lab environment.
4. **Documentation:** Detailed logging of final states and configurations.

---

## ⚙️ Key Features
* **Redundancy:** Implementation of self-healing protocols for high availability.
* **Scalability:** Modular design to facilitate network growth.
* **Security:** Application of industry-standard measures to protect infrastructure.
* **Reproducibility:** Documentation-driven approach to ensure rebuildability.

---

## 🛠️ Tools & Technologies
* **Hardware:** Cisco Switches & Routers (Lab environment).
* **Simulation:** Cisco Packet Tracer.
* **Version Control:** Git & GitHub.
* **Format:** Markdown documentation.
