## 📋 Project Overview

This repository contains all documentation, simulation files, and device configurations for the **Connecting and Securing Networks** course project. The goal is to design and build a resilient enterprise network connecting two sites — New York and Brussels — capable of automatically recovering from link or device failures.

The project follows a structured four-phase methodology:

1. **Preparation** — Research, requirements gathering, and theoretical network design.
2. **Simulation** — Building and testing the network in Cisco Packet Tracer.
3. **Implementation** — Deploying the design on physical hardware in a lab environment.
4. **Documentation** — Logging all configurations, decisions, and final network states.

---

## ✨ Key Features

- **Redundancy** — Self-healing protocols ensure high availability and automatic failover.
- **Scalability** — Modular design that can grow without major redesign.
- **Security** — Industry-standard measures applied throughout the infrastructure.
- **Reproducibility** — Every configuration and decision is documented for full rebuildability.
